# 今天吃什么微信小程序（旧原生归档）

这个目录是旧的原生微信小程序实现，已经从主入口迁移到 `legacy/miniprogram-native/`。

当前小程序主线在 `food-uniapp/`，微信开发者工具默认应导入仓库根目录或 `food-uniapp/dist/build/mp-weixin`。

## 打开方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择：`/Users/macminim4/Documents/New project/food/legacy/miniprogram-native`
4. AppID 按当前微信后台项目配置填写。
5. 导入后编译预览。

## 当前功能

- 首页直接点选想吃的菜，支持搜索、收藏和刷新未选菜。
- 默认按 3 人、80 元、18:30 前做好、慢一点的家庭晚餐生成。
- 生成三套晚餐方案，第一套优先围绕首页选中的菜生成。
- 展示买菜清单、按点上桌计划、做饭顺序、每道菜做法。
- 本地记住首页已选菜、可见菜、收藏菜和上次选中的一桌菜。

## 后续接服务器

当前生成逻辑是本地 mock 数据，位于 `utils/mealPlans.js`。
接云服务器后，把结果页里的本地生成替换为 `wx.request` 即可。
